# Changelog

All notable changes to dlux. The format follows [Keep a Changelog](https://keepachangelog.com/),
and dlux uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-09

### Features

- workspace skeleton, aria2 RPC client and aria2 auto-spawn (#1)
- TUI layout, Tokyo Night theme, live download list and speed graph
- complete mouse support and keyboard shortcuts
- add dialog, global controls and speed limits
- yt-dlp and ffmpeg integration with the format picker
- web backend with REST API and live WebSocket
- web frontend embedded in the binary
